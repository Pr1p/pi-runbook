# Journal

按时间线记录理解 pi 的思考过程。每篇 entry 记录当时的困惑、试错和顿悟，不是为了完美，是为了保留思考的痕迹。

## 约定

- 文件名格式 `NNN-简短描述.md`，从 001 开始
- 每篇包含：日期、看了什么、当时的理解、卡住的地方、后来的突破
- 不需要写完就改——journal 是流水账，想改的东西沉淀到 docs/ 里

## 模板

```
# NNN - 标题

日期：YYYY-MM-DD

## 在看什么

（简述当时在读哪块代码）

## 当时的理解

（你以为的，哪怕后来发现是错的）

## 卡住的地方

（哪个概念想不通、哪个设计决策不理解）

## 突破

（怎么想通的——读到了什么、跑了什么实验、跟谁聊了）
```
